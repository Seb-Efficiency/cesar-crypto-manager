⚙️ Configuration webhooks

Renseigne l'URL de base de tes webhooks n8n.
Les paramètres sont sauvegardés dans ton navigateur.

Sans slash final — ex : https://n8n.efficiency-hub.co/webhook
Webhooks à créer dans n8n
GET /cesar-portfolio→ retourne positions DCA + Trading
POST /cesar-dca→ achat ou vente DCA
GET /cesar-trading-positions→ positions trading ouvertes
POST /cesar-trading-buy→ ouvrir une position trading
POST /cesar-trading-sell→ clôturer une position trading
GET /cesar-trading-history→ historique des positions clôturées
Cryptos personnalisées

Si une de tes cryptos n'est pas reconnue, ajoute sa correspondance CoinGecko ici.
Format : SYMBOLE:coingecko-id (une par ligne)

Trouve l'ID sur coingecko.com → page de la crypto → URL : coingecko.com/en/coins/cet-id
